---
description: 日本語Markdownを検査し、安全に直せる指摘を修正します。
argument-hint: "[Markdownファイル]"
disable-model-invocation: true
---

`$ARGUMENTS`にMarkdownファイルが指定されていれば、そのファイルだけを検査してください。

指定がない場合は、現在の依頼で作成または編集したMarkdownが特定できれば、そのファイルだけを検査してください。対象を特定できない場合はプロジェクト内のMarkdownを検査します。

対象ファイルを指定する場合は、次のコマンドの末尾へプロジェクトルートからのパスを追加してください。複数ファイルを指定できます。

```console
node "${CLAUDE_PLUGIN_ROOT}/scripts/claude-lint.mjs"
```

結果は重要度別に表示されます。

- `[AIで修正可能]`: 文意を保てる範囲で修正できます
- `[書き手に確認]`: 推測で埋めず、利用者へ質問してください
- `[要確認]`: 不確実な理由を利用者へ伝えてください

AIで修正可能な指摘だけを一度修正し、同じ対象でコマンドを再実行してください。警告を消すために意味を薄めたり、ルールを無効化したり、許可リストへ追加したりしてはいけません。

修正により意味が変わる可能性がある指摘、書き手の入力が必要な指摘、再検査後も残る指摘は変更せず、利用者へ簡潔に伝えてください。
